## Frameworks and Libraries

### Deep Learning Frameworks
- **[TensorFlow](https://www.tensorflow.org/)** - End-to-end open source platform for machine learning
- **[PyTorch](https://pytorch.org/)** - Open source machine learning framework based on the Torch library
- **[Keras](https://keras.io/)** - High-level neural networks API, running on top of TensorFlow
- **[JAX](https://github.com/google/jax)** - High-performance numerical computing library with automatic differentiation

### Machine Learning Libraries
- **[scikit-learn](https://scikit-learn.org/)** - Machine learning library for Python
- **[XGBoost](https://xgboost.readthedocs.io/)** - Optimized distributed gradient boosting library
- **[LightGBM](https://lightgbm.readthedocs.io/)** - Fast, distributed, high performance gradient boosting framework
- **[CatBoost](https://catboost.ai/)** - Gradient boosting on decision trees library

### Natural Language Processing
- **[Hugging Face Transformers](https://huggingface.co/transformers/)** - State-of-the-art NLP models
- **[spaCy](https://spacy.io/)** - Industrial-strength Natural Language Processing
- **[NLTK](https://www.nltk.org/)** - Natural Language Toolkit
- **[Gensim](https://radimrehurek.com/gensim/)** - Topic modeling and document similarity

### Computer Vision
- **[OpenCV](https://opencv.org/)** - Open source computer vision and machine learning software library
- **[Detectron2](https://github.com/facebookresearch/detectron2)** - Facebook AI Research's object detection library
- **[YOLO](https://github.com/ultralytics/yolov5)** - Real-time object detection system
- **[MMDetection](https://github.com/open-mmlab/mmdetection)** - Object detection toolbox
